# CareFlow: Clinical Pathway Process Mining

## 1. Project Overview

CareFlow is a team-based healthcare data analytics project. Our goal is to study patient journeys through hospital processes and understand where delays, bottlenecks, or differences in treatment pathways may occur.

## 2. Project Objective

The main objective is to analyze healthcare data, understand the sequence of patient activities, and present useful findings through process maps, charts, and a dashboard. We will work together to explore the data and identify possible areas for improvement.

## 3. Dataset

Our team plans to select a suitable healthcare dataset from Kaggle. We will review its columns and data quality to check whether it contains patient or case identifiers, activity names, and timestamps required for process mining.

## 4. Technologies

- **Kaggle:** Finding a suitable healthcare dataset.
- **Python and Jupyter Notebook:** Exploring, cleaning, and preparing the data.
- **SQL and BigQuery:** Querying and analyzing the data.
- **dbt:** Organizing and transforming data.
- **PM4Py:** Analyzing process flows and patient pathways.
- **Power BI:** Creating visualizations and an interactive dashboard.
- **GitHub:** Sharing code, tracking changes, and coordinating team contributions.

## 5. Team Responsibilities

The project work will be divided among team members so that everyone can contribute to a different part of the workflow.

- **Dataset and Documentation:** Research healthcare datasets, check their suitability, and document the project.
- **Python and Data Cleaning:** Explore the selected dataset, handle missing or duplicate values, and prepare the data.
- **SQL and Data Transformation:** Use SQL and, where available, BigQuery and dbt to organize and transform the data.
- **Process Mining and Dashboard:** Use PM4Py to study process flows where the data supports it, and develop visualizations in Power BI.

Team members will share updates and review each other's work through GitHub.

## 6. Planned Workflow

1. Discuss the project requirements and select a suitable healthcare dataset.
2. Examine the dataset structure and assess its quality.
3. Clean and prepare the data using Python.
4. Organize and analyze the data using SQL and related tools.
5. Apply process mining to explore patient pathways if the required event data is available.
6. Create charts and a Power BI dashboard to communicate the findings.
7. Document the results, limitations, and contributions of the team.
