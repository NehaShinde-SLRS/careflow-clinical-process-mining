# CareFlow Dataset Notes

## Dataset Name
HospitalOPD

## Dataset Source
Mendeley Data

## Official Link
https://data.mendeley.com/datasets/j2hd2239dr/1

## Dataset Description
HospitalOPD contains anonymized outpatient healthcare event records. It covers patient journeys involving appointments, consultations, laboratory investigations, medical imaging, and pharmacy services.

## Dataset Size
The published dataset description reports 62,422 patient-event records.

## Project Purpose
This dataset will be used in CareFlow to explore outpatient workflows, identify common activity sequences, and investigate waiting times between healthcare services.

## Planned Analysis
- Check data quality and missing values.
- Examine appointment, laboratory, imaging, prescription, and pharmacy timestamps.
- Convert the data into an event-log format for process mining.
- Explore workflow patterns and elapsed times.
- Prepare visualizations for a future Power BI dashboard.

## Limitations
The dataset structure and timestamps must be validated before analysis. Calculated time differences will be interpreted carefully, and any findings will be reported as associations rather than proven causes.
