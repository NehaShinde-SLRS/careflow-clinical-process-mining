# careflow-clinical-process-mining
CareFlow analyzes synthetic patient data to understand hospital workflows and identify potential delays. Using Python, BigQuery, dbt, PM4Py, and Power BI, the project explores patient pathways and visualizes findings through dashboards. 

Project Objectives
Understand outpatient patient journeys through activity sequences.
Prepare and validate healthcare event logs.
Analyze activity frequencies and transitions.
Discover process flows using PM4Py.
Identify potential workflow bottlenecks for further investigation.
Present findings through data visualizations and dashboards.

Tools and Technologies
Python: Data cleaning, preprocessing, and analysis.
Pandas: Data manipulation and event-log preparation.
BigQuery: SQL-based data analysis and validation.
SQL: Activity, case, and transition analysis.
dbt: Data transformation workflow.
PM4Py: Process discovery and process-map generation.
Power BI: Dashboard development and visualization.
